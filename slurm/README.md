# Slurm Notes

`dual_backbone_inorg.slurm` is the portable reviewer-facing Slurm template. Submit it from the repository root after creating `logs/` and preparing the Python environment/checkpoints described in `../REPRODUCIBILITY.md`.

Other Slurm files in this directory are archived provenance scripts from development runs. They may contain cluster-specific module, partition, or path assumptions and should be treated as historical records unless adapted for a new system.
